File backup & recovery

A recovery copy of device scores is saved before each restore. Backups contain your cricket records; keep downloaded files somewhere safe.

Google connection setup

One-time setup: enable Google Drive API, create an OAuth Web client and add this site's origin under Authorized JavaScript origins. Use the same client ID on every device. No client secret is needed.

Backups are private to this app and account, hidden from the Drive file list. Google tokens stay in memory and are cleared when this page closes. Disconnect keeps your backups.
